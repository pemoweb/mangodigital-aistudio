# 🥭 Mango Digital

**Agencia digital especializada en diseño web, marketing digital, SEO y soluciones de hosting.**

Mango Digital nace con el objetivo de ayudar a emprendedores, autónomos y pequeñas empresas a crear y mejorar su presencia en Internet mediante soluciones digitales modernas, accesibles y adaptadas a sus necesidades.

🌐 **Web:** [mangodigital.es](https://mangodigital.es)

---

## 🚀 Sobre el proyecto

Este repositorio contiene el desarrollo del sitio web de **Mango Digital**.

El proyecto comienza como una **maquetación frontend independiente**, utilizando tecnologías web estándar, para definir la identidad visual, estructura, experiencia de usuario y arquitectura de contenidos antes de evolucionar hacia una aplicación completa.

La primera etapa está centrada en:

* 🎨 Diseño y maquetación responsive
* 📱 Enfoque Mobile First
* 🔎 Arquitectura orientada a SEO
* ⚡ Rendimiento y carga rápida
* 🧩 Componentes reutilizables
* 🧮 Calculadora de presupuesto
* 📄 Páginas independientes para servicios
* 📢 Llamadas a la acción orientadas a conversión

---

## 🛠️ Tecnologías

La primera versión utiliza tecnologías frontend estándar:

* **HTML5**
* **CSS3**
* **JavaScript**
* **Responsive Design**
* **SEO técnico**
* **SVG**
* **Google Fonts**

La intención es mantener una base frontend limpia y sencilla antes de incorporar un backend.

### Próxima evolución

El proyecto está preparado conceptualmente para evolucionar hacia:

* **Laravel**

* Gestión de servicios
* Gestión de presupuestos

## 🎯 Servicios

Mango Digital está orientado a ofrecer diferentes soluciones digitales:

### 🌐 Diseño y desarrollo web

Diseño de páginas web modernas, responsive y adaptadas a las necesidades de cada proyecto.

### 🔎 SEO

Optimización de sitios web para mejorar su estructura, indexación y presencia en buscadores.

### 📣 Marketing digital

Estrategias y herramientas digitales para ayudar a empresas y emprendedores a mejorar su presencia online.

### 🖥️ Hosting

Soluciones de alojamiento web y servicios relacionados con la presencia digital.

### 🧮 Presupuestos

El proyecto incorpora una **calculadora de presupuesto** para permitir al visitante configurar los servicios que necesita y obtener una estimación inicial.

---

## 📱 Mobile First

Mango Digital se desarrolla siguiendo un enfoque **Mobile First**.

La experiencia debe funcionar correctamente desde:

* 📱 Smartphones
* 📱 Tablets
* 💻 Portátiles
* 🖥️ Monitores de escritorio

El diseño responsive no se considera una adaptación posterior, sino una parte fundamental de la arquitectura inicial.

---

## 🔍 SEO

La estructura del sitio está pensada para trabajar el SEO desde el principio.

Entre los objetivos:

* URLs limpias
* Páginas independientes por servicio
* Etiquetas `<title>` específicas
* Meta descriptions
* Encabezados semánticos
* HTML5 semántico
* Datos estructurados cuando corresponda
* Sitemap
* Robots.txt
* Optimización de imágenes
* Buen rendimiento
* Accesibilidad
* Enlaces internos

La intención es evitar construir una única landing page y posteriormente intentar dividirla para SEO.

---

## 🧮 Calculadora de presupuesto

Una de las funcionalidades principales del proyecto es la **Calculadora de Presupuesto Mango Digital**.

El visitante podrá seleccionar diferentes necesidades, por ejemplo:

* Página web
* Tienda online
* SEO
* Marketing digital
* Hosting
* Mantenimiento
* Servicios adicionales

La calculadora generará una estimación orientativa y posteriormente podrá utilizarse como punto de entrada para solicitar un presupuesto personalizado.

> Los precios y condiciones comerciales definitivos serán configurables y no forman parte necesariamente de la lógica frontend inicial.
